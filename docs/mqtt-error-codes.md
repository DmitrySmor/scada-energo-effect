# Коды результатов прикладных подтверждений (согласовано 2026-10-29, ТЗ п.5.1/7.1)

| status   | error_code          | смысл                                   |
|----------|---------------------|-----------------------------------------|
| stored   | —                   | данные зафиксированы в БД (после commit)|
| stored   | —                   | повтор message_id: согласованный результат без дублей |
| rejected | PARSE_ERROR         | некорректный JSON                       |
| rejected | SCHEMA_ERROR        | нет обязательных полей общей схемы      |
| rejected | UNKNOWN_DEVICE      | устройство не зарегистрировано          |
| rejected | TOPIC_MISMATCH      | object/device из топика не совпадают    |
| rejected | VALIDATION_ERROR    | data не соответствует схеме устройства  |
| rejected | INTERNAL_ERROR      | сбой обработки (повтор устройством допустим) |

Перечень зафиксирован как базовый; новые коды добавляются только через изменение этого документа (ТЗ п.21).
