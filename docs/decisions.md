## Следствия для реализации

* Спецификация MQTT зафиксирована в docs/mqtt-spec.md (топики ack, MQTT 5, параметры сессий).
* Коды результатов ack зафиксированы в docs/mqtt-error-codes.md.
* До решения по п.1 аутентификация API проектируется так, чтобы замена JWT на сессионные cookie затрагивала только `core/security.py`, `core/deps.py` и `api/routes/auth.py`.

## Ещё не согласовано (открытые вопросы п.21)

* Количество устройств и частота передачи сообщений.
* Схемы `data` для типов оборудования.
* Механизм REST-аутентификации (вопрос 1 — на рассмотрении).
* Каналы доставки уведомлений.
* Место хранения резервных копий вне основного диска.
* Пороговые значения отсутствия данных.
* Сроки хранения показаний, исходных сообщений и логов.
* Ограничения частоты запросов API.
* Требования RPO/RTO.
